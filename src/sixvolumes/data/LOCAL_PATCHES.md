# 本地集成修复（2026-10-23）

六库来源及原始哈希见 UPSTREAM_PROVENANCE.json。审计目录原件未改，以下仅发生于本目录 vendor 与新集成层。原报告中历史状态以其原日期为准；本文件为当前集成补充。

- **Tellan本地代理**：当前Windows环境的系统HTTP代理未绕过127.0.0.1，闭端口错误被中间代理改写为空502。修复为仅字面loopback/localhost上游使用禁代理的urllib opener；外部上游仍尊重代理配置。测试客户端也明确直连本地fixture，增加恶意/失效proxy环境回归。没有把测试失败改成忽略。
- **Tellan可选依赖**：真实tokenizer集成测试在未装tiktoken时显式skip；不支持模型族的门禁使用注入式tokenizer并保证不会下载；warmup已经注入loader时不再强制导入真实依赖。完整evaluation环境仍跑真实tokenizer路径。
- **Worddael复现**：上游报告随可选jieba是否存在改变。增加ContextVar固定core/jieba评测配置，默认core不调用任何可选分词器，避免环境变化或隐式BPE下载。保存上游jieba历史报告，重新生成当前core报告；跨配置数字不可混用。算法没有调参。
- **Siftan导出**：公开API补导出build_index，与使用示例一致；算法不变。
- **Worddael硬预算（2026-10-24，见到失败后的工程修复）**：冻结外测发现4块为257字、超过256上限。根因为标点清理允许左块吸收1–2字且不接收预算，上游测试也容许+2。现对长原子句先拆分、边界移动同时约束左右块、overlap计入最终硬上限。无法兼顾标点时优先保留预算与完整精确偏移，不通过丢字规避超限。新增6条边界回归与1条集成回归，收紧原有预算断言；两相邻满额块无法移动边界的例外明确进入标点测试。冻结结果保持原样，已见数据复验只列工程证据；没有重跑或改写独立RAG分数，没有调Siftan阈值。
- **新PII规范化适配层**：六卷集成层新增有界NFKC/零宽/孤立空格识别视图，限定身份证、银行卡、手机、邮箱、统一社会信用代码，维护逐字符原始偏移，禁止跨行或双空白拼接。保留native配置。此项由外部评测发现失效后产生，因此只能报告为工程修复和诊断，必须用新的独立保留集再次验证。
- **能力口径**：Helan Vault 为明文映射，不提供加密/密钥；Tellan哈希链不证明根信任、不防整链重算；Sothstan不能以mock基线冒充真实身份验证；报告对缺配置输出unavailable并支持严格退出码。

完整来源差异由 scripts/package_release.py 生成 LOCAL_CHANGES.json。没有提交到上游仓库、发布PyPI或声称外部社区采用。
