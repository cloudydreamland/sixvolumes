# 证据边界与接入协议

## 数据流与可重复性

报告schema为sixvolumes.evidence/v1。每篇文档保留原文件SHA-256、脱敏文件SHA-256、实体原始字符区间和转换段。复制段可逐字符映射；占位符部分映射到原始实体完整区间，不假装存在逐字同长关系。切块的start/end引用脱敏文本，其source_spans引用原文；两个坐标系不能混用。

report.evidence_sha256从除generated_at/runtime外的标准化JSON生成；artifacts.json对每个工件按字节哈希。索引gzip演示包固定mtime，避免同输入不同索引文件哈希。以上只给内容一致性，不给独立真实性。

## 未补齐的外部验证

- 真实用户采用与生产效果没有由本工程完成。新增统一CLI、wheel、测试不是外部用户证明。
- 默认示例是原创合成文档；引用来源和测试题也是合成。真实账本/模型基线缺失会显示unavailable。
- PII规范化修复是看到失效后的诊断改进。独立评测原生Helan数据必须保留，不能替换。严格不跨行也会漏掉跨行实体，这是显式取舍。
- 规则脱敏仍可能漏检或误报，不保证合规结果；Vault明文映射必须独立保护。
- 引语逐字找到只证明给定来源里有这段字，不证明观点正确、文献存在或引用符合学术规范。
- 13-gram污染检测是字面重叠检测；未命中不证明训练未污染。近重复层是advisory。
- Tellan启发式包围盒并非真实账单验证；历史模型价格未按2026-10-23重新核实。
- Sothstan非demo的标记和official_baseline_source来自用户声明，仍需真实采集记录佐证；转发攻击不可能仅靠这类有限黑盒检查完全排除。

## 外部评测交接

独立评测目录位于同级 `../评测`，不属于统一管线内置演示。评测源数据、划分、方法版本、模型权重、原始输出与失败项应一起提交。这个工程没有为提高独立集成绩更改切块、污染或引用算法。

## 安全分享

默认不输出原文实体值和原始污染命中n-gram，只输出范围与计数。脱敏内容仍可能含未识别敏感信息。原始输入、外部API密钥、Vault与真实账本均不应放入公开包；六卷工程不把它们发送到外部服务。唯一外部调用入口是用户显式提供的sothstan配置且加--allow-live。
